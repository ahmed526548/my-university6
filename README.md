# بوابة جامعة بني سويف الأهلية

تطبيق ويب للطلاب يحتوي على:

- 📚 **مكتبة المحاضرات** مع تلخيصات عربية وإنجليزية
- 🤖 **مساعد جامعي ذكي** يشرح المحاضرات
- 📅 **جدول المحاضرات** لجروب 1 و جروب 2
- ⭐ **نظام المفضلة** (يُحفظ في المتصفح)
- 📊 **شريط تقدم** لكل مادة

## التشغيل

```bash
# تثبيت المكتبات
npm install

# تشغيل في وضع التطوير
npm run dev

# بناء النسخة النهائية
npm run build
```

بعد `npm run dev` افتح الرابط الذي يظهر (عادة http://localhost:5173)

## التقنيات

- React 18
- Vite
- Tailwind CSS
- Lucide React (الأيقونات)

## هيكل المشروع

```
src/
├── components/     # مكونات الواجهة
├── data/           # بيانات المواد والمحاضرات والجداول
├── App.jsx
├── main.jsx
└── index.css
```

## ملاحظات

- البيانات حالياً ثابتة (hardcoded). يمكن لاحقاً ربطها بـ API أو Firebase.
- المساعد يعمل بردود ذكية بسيطة حسب الكلمات المفتاحية (يمكن تطويره لاحقاً بـ AI حقيقي).
- المفضلة تُحفظ في `localStorage`.
